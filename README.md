# DREAMS
**DREAMS – Disaster Response and Emergency Assistance Management System**  DREAMS is a C++ and web-based disaster response management system designed to improve emergency coordination and resource allocation. It uses rule-based disaster severity classification, priority queues, resource management, and Dijkstra’s shortest-path algorithm to prioritize incidents and support efficient emergency response.  The project also features an interactive Patiala map, a live incident dashboard, Firebase Realtime Database synchronization, and severity-based alert notifications to support real-time disaster monitoring and coordination.
